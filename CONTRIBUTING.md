# Contribution Guidelines

Thank you for your interest in contributing to Awesome LLMOps!

## Adding a new item

Please ensure your pull request adheres to the following guidelines:

- **Search previous suggestions** before making a new one to avoid duplicates.
- **Make an individual pull request** for each suggestion.
- **Use the following format:** `[Package Name](link) - Short description.`
- **Descriptions should:**
  - Start with a capital letter
  - End with a period
  - Be concise (under 100 characters)
  - Not start with "A" or "An"
- **Check your spelling and grammar.**
- **New categories or improvements** to the existing categorization are welcome.
- **Keep descriptions short and simple**, but descriptive.
- **Make sure your text editor is set to remove trailing whitespace.**

## Quality standards

To be included, projects should meet the following criteria:

- **Actively maintained** - Last commit within 6 months (exceptions for stable projects)
- **Well documented** - Has a README with clear usage instructions
- **Production-ready** - Used by companies or has significant community adoption
- **Unique value** - Offers something different from existing entries

## Pull request process

1. Fork this repository
2. Create a new branch: `git checkout -b add-new-tool`
3. Make your changes to `README.md`
4. Run `npx awesome-lint` to check for errors
5. Commit your changes: `git commit -am 'Add new tool'`
6. Push to the branch: `git push origin add-new-tool`
7. Submit a pull request

## Updating your PR

If the maintainers request changes:

- Make the required updates
- Re-run `npx awesome-lint` to ensure no new errors
- Push the changes to the same branch

Thank you for your contributions!
